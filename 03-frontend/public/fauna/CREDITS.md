# Créditos de las fotos de campo

Las fotos de referencia de cada espécimen 3D salen de Wikimedia Commons
(observaciones de iNaturalist). Las láminas de estudio se elaboraron a
partir de esas fotos.

Los modelos 3D los generó angelzambranojaraba en Tripo Studio a partir
de las fotos de campo:

- `public/fauna/models/aves.glb` — *Ortalis garrula*
- `public/fauna/models/mamiferos.glb` — *Alouatta seniculus*
- `public/fauna/models/anfibios.glb` — *Rhinella humboldti*
- `public/fauna/models/reptiles.glb` — *Anolis auratus*
